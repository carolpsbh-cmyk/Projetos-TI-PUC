# Semáforo Arduino

Projeto desenvolvido no Tinkercad para controle de semáforo de veículos e pedestres utilizando LEDs e buzzer.

## Componentes
- Arduino Uno
- LEDs vermelho, amarelo e verde
- Buzzer
- Resistores

## Funcionamento
O sistema alterna os sinais de trânsito e emite alerta sonoro para travessia de pedestres.
